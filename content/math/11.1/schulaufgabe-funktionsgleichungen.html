Schulaufgabe Funktions­gleichungen gesucht

Die Aufgaben vom Arbeitsblatt „Funktionsgleichungen gesucht“ und drei zusätzliche Übungsaufgaben im Stil der Arbeit. Alle Lösungen in den fünf Schritten wie im Buch: (1) Ansatz · (2) Eigenschaften · (3) Gleichungen · (4) LGS lösen · (5) Resultat.

Hilfsmittel: WTR, Formelsammlung · Bearbeitungszeit: ca. 90 Minuten · Gesamt: 70 Punkte
Bestimmen Sie jeweils die Funktionsgleichung. Notieren Sie Ansatz, Eigenschaften, Gleichungen und den Lösungsweg des LGS.
5 Aufgaben

Aufgabe 1 · Steckbriefe 32 P

Arbeitsblatt „Funktionsgleichungen gesucht“, Aufgabe 1

  1. Der Graph einer ganzrationalen Funktion 3. Grades ist punktsymmetrisch zum Ursprung und hat den Tiefpunkt \(T(2\,|\,-4)\). (6 P)
  2. Der Graph einer ganzrationalen Funktion 3. Grades geht durch den Koordinatenursprung und hat an der Stelle 2 eine waagerechte Tangente. Außerdem hat er eine Tangente im Wendepunkt \(W(4\,|\,y_W)\) mit der Steigung \(-4\). (8 P)
  3. Der Graph einer ganzrationalen Funktion 3. Grades ist punktsymmetrisch zum Punkt \(P(-1\,|\,0)\) und schneidet die x-Achse bei 2 unter einem Winkel von 45°.
    (Tipp 1: Jede ganzrationale Funktion 3. Grades ist punktsymmetrisch zum Wendepunkt.) (Tipp 2: Überlegen Sie, welcher Steigung ein Schnittwinkel von 45° entspricht.) (10 P)
  4. Der Graph einer ganzrationalen Funktion 4. Grades ist symmetrisch zur y-Achse. Im Punkt \(P(2\,|\,0)\) hat der Graph die Steigung 2, und bei \(x_W = -1\) befindet sich eine Wendestelle. (8 P)
Lösung zu a)

(1) Ansatz für die Funktionsgleichung
Wir setzen die ganzrationale Funktion dritten Grades unter Verwendung der Parameter \(a, b, c\) und \(d\) allgemein an. Außerdem notieren wir den Funktionsterm von \(f'\).

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

(2) Eigenschaften der Funktion f

1. punktsymmetrisch zum Ursprung

2. Tiefpunkt \(T(2\,|\,-4)\)
(Extremstelle \(x = 2\), Funktionswert \(y = -4\))

(3) Umsetzen der Eigenschaften in Gleichungen

1.nur ungerade Potenzen\(b = 0,\; d = 0\) 2.\(f(2) = -4\)\(8a + 2c = -4\) \(f'(2) = 0\)\(12a + c = 0\)

(4) Lösen des Gleichungssystems

I:\(8a + 2c = -4\) II:\(12a + c = 0\)\(2\cdot\text{II} - \text{I} \to\)

III: \(16a = 4\)

\(a = 0{,}25\)

in II: \(3 + c = 0\)

\(c = -3\)

(5) Resultat

\(f(x) = 0{,}25x^3 - 3x\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Probe: \(f(2) = 2 - 6 = -4\) ✓ · \(f'(2) = 3 - 3 = 0\) ✓ · \(f''(2) = 1{,}5\cdot 2 = 3 > 0\) → wirklich ein Tiefpunkt ✓

Lösung zu b)

(1) Ansatz für die Funktionsgleichung

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Punkt \(O(0\,|\,0)\)

2. waagerechte Tangente bei \(x = 2\)

3. Wendepunkt \(W(4\,|\,y_W)\)
(Wendestelle \(x = 4\), \(y_W\) unbekannt)

4. Steigung im Wendepunkt: \(-4\)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(0) = 0\)\(d = 0\) 2.\(f'(2) = 0\)\(12a + 4b + c = 0\) 3.\(f''(4) = 0\)\(24a + 2b = 0\) 4.\(f'(4) = -4\)\(48a + 8b + c = -4\)

(4) Lösen des Gleichungssystems

I:\(12a + 4b + c = 0\) II:\(24a + 2b = 0\)\(\to b = -12a\) (IV) III:\(48a + 8b + c = -4\)\(\text{III} - \text{I} \to\)

V: \(36a + 4b = -4\)

IV in V: \(36a - 48a = -4\)

\(-12a = -4\)

\(a = \tfrac13\)

in IV: \(b = -4\)

in I: \(4 - 16 + c = 0 \Rightarrow c = 12\)

(5) Resultat

\(f(x) = \tfrac13 x^3 - 4x^2 + 12x\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Probe: \(f'(x) = x^2 - 8x + 12\): \(f'(2) = 4 - 16 + 12 = 0\) ✓ · \(f'(4) = 16 - 32 + 12 = -4\) ✓ · \(f''(x) = 2x - 8\): \(f''(4) = 0\) ✓

Lösung zu c)

(1) Ansatz für die Funktionsgleichung

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Wendepunkt \(W(-1\,|\,0)\)
(Tipp 1: punktsymmetrisch zu \(P\) ⇒ \(P\) ist der Wendepunkt)

2. Nullstelle bei \(x = 2\)

3. Steigung bei \(x = 2\): \(\tan 45° = 1\)
(Tipp 2)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(-1) = 0\)\(-a + b - c + d = 0\) \(f''(-1) = 0\)\(-6a + 2b = 0\) 2.\(f(2) = 0\)\(8a + 4b + 2c + d = 0\) 3.\(f'(2) = 1\)\(12a + 4b + c = 1\)

(4) Lösen des Gleichungssystems

I:\(-a + b - c + d = 0\) II:\(-6a + 2b = 0\)\(\to b = 3a\) (V) III:\(8a + 4b + 2c + d = 0\)\(\text{III}-\text{I} \to\) IV:\(12a + 4b + c = 1\)

VI: \(9a + 3b + 3c = 0 \;\big|:3\)

\(3a + b + c = 0\)

V in VI: \(6a + c = 0 \Rightarrow c = -6a\) (VII)

V, VII in IV:

\(12a + 12a - 6a = 1\)

\(18a = 1 \Rightarrow a = \tfrac{1}{18}\)

in V: \(b = \tfrac16\)

in VII: \(c = -\tfrac13\)

in I: \(d = -\tfrac49\)

Wie kommt man auf d?

I: \(-\tfrac{1}{18} + \tfrac16 - \big(-\tfrac13\big) + d = 0 \;\Rightarrow\; \tfrac{-1 + 3 + 6}{18} + d = 0 \;\Rightarrow\; \tfrac{8}{18} + d = 0 \;\Rightarrow\; d = -\tfrac49\)

(5) Resultat

\(f(x) = \tfrac{1}{18}x^3 + \tfrac16 x^2 - \tfrac13 x - \tfrac49\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Probe: \(f(2) = \tfrac49 + \tfrac23 - \tfrac23 - \tfrac49 = 0\) ✓ · \(f'(2) = \tfrac{12}{18} + \tfrac46 - \tfrac13 = 1\) ✓ · \(f''(-1) = -\tfrac13 + \tfrac13 = 0\) ✓

Lösung zu d)

(1) Ansatz für die Funktionsgleichung
Achsensymmetrie zur y-Achse: Nur gerade Potenzen, d. h. \(b = d = 0\).

\(f(x) = ax^4 + cx^2 + e\)

\(f'(x) = 4ax^3 + 2cx\)

\(f''(x) = 12ax^2 + 2c\)

(2) Eigenschaften der Funktion f

1. Punkt \(P(2\,|\,0)\)

2. Steigung in \(P\): 2

3. Wendestelle \(x_W = -1\)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(2) = 0\)\(16a + 4c + e = 0\) 2.\(f'(2) = 2\)\(32a + 4c = 2\) 3.\(f''(-1) = 0\)\(12a + 2c = 0\)

(4) Lösen des Gleichungssystems

I:\(16a + 4c + e = 0\) II:\(32a + 4c = 2\) III:\(12a + 2c = 0\)\(\text{II} - 2\cdot\text{III} \to\)

IV: \(8a = 2\)

\(a = 0{,}25\)

IV in III: \(3 + 2c = 0 \Rightarrow c = -1{,}5\)

in I: \(4 - 6 + e = 0 \Rightarrow e = 2\)

(5) Resultat

\(f(x) = 0{,}25x^4 - 1{,}5x^2 + 2\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Aufgabe 2 · Das Abwasserauffangbecken 14 P

Arbeitsblatt „Funktionsgleichungen gesucht“, Aufgabe 2

Der Zu- und Ablauf eines Abwasserauffangbeckens lässt sich für \(t \in [0;\,12]\) annähernd durch eine ganzrationale Funktion dritten Grades beschreiben. Zum Zeitpunkt \(t = 0\) enthält das Becken 300 m³ Wasser. Nach 12 Stunden ist das Becken leer. Nach 4 Stunden hat der Wasserstand seinen Höchstwert erreicht. Er liegt dann bei 500 m³. Geben Sie die Funktionsgleichung an, die den Füllstand in m³ in Abhängigkeit der abgelaufenen Zeit in Stunden angibt.

Lösung anzeigen

(1) Ansatz für die Funktionsgleichung
\(t\): Zeit in Stunden, \(V(t)\): Füllstand in m³.

\(V(t) = at^3 + bt^2 + ct + d\)

\(V'(t) = 3at^2 + 2bt + c\)

(2) Eigenschaften der Funktion V

1. Punkt \((0\,|\,300)\) – Anfangsfüllung

2. Punkt \((12\,|\,0)\) – nach 12 h leer

3. Hochpunkt \(H(4\,|\,500)\)
(Extremstelle \(t = 4\), Funktionswert 500)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(V(0) = 300\)\(d = 300\) 2.\(V(12) = 0\)\(1728a + 144b + 12c + 300 = 0\) 3.\(V'(4) = 0\)\(48a + 8b + c = 0\) \(V(4) = 500\)\(64a + 16b + 4c + 300 = 500\)

(4) Lösen des Gleichungssystems (mit \(d = 300\) bereits eingesetzt)

I:\(1728a + 144b + 12c = -300\)\(:12 \to\) II:\(48a + 8b + c = 0\) III:\(64a + 16b + 4c = 200\)\(:4 \to\)
IV:\(144a + 12b + c = -25\)\(\text{IV}-\text{II} \to\) V:\(16a + 4b + c = 50\)\(\text{II}-\text{V} \to\)
VI:\(96a + 4b = -25\)\(\text{VI}-\text{VII} \to\) VII:\(32a + 4b = -50\)

VIII: \(64a = 25\)

\(a = \tfrac{25}{64} \approx 0{,}39\)

in VII: \(12{,}5 + 4b = -50\)

\(b = -15{,}625\)

in II: \(18{,}75 - 125 + c = 0\)

\(c = 106{,}25\)

(5) Resultat

\(V(t) = 0{,}39\,t^3 - 15{,}625\,t^2 + 106{,}25\,t + 300\) beschreibt den Füllstand (in m³) nach \(t\) Stunden.

Genau: \(a = \tfrac{25}{64} = 0{,}390625\). Probe: \(V(4) = 25 - 250 + 425 + 300 = 500\) ✓ · \(V(12) = 675 - 2250 + 1275 + 300 = 0\) ✓ · \(V'(4) = 18{,}75 - 125 + 106{,}25 = 0\) ✓

Aufgabe 3 · Parabel mit Scheitelpunkt 6 P

Eine quadratische Funktion hat den Scheitelpunkt \(S(2\,|\,-1)\) und ihr Graph geht durch den Punkt \(P(0\,|\,3)\). Bestimmen Sie die Funktionsgleichung.

Lösung anzeigen

(1) Ansatz für die Funktionsgleichung

\(f(x) = ax^2 + bx + c\)

\(f'(x) = 2ax + b\)

(2) Eigenschaften der Funktion f

1. Scheitelpunkt \(S(2\,|\,-1)\)
(Extremstelle \(x = 2\), Funktionswert \(-1\))

2. Punkt \(P(0\,|\,3)\)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(2) = -1\)\(4a + 2b + c = -1\) \(f'(2) = 0\)\(4a + b = 0\) 2.\(f(0) = 3\)\(c = 3\)

(4) Lösen des Gleichungssystems

\(c = 3\) in I:

IV: \(4a + 2b = -4\)

II: \(4a + b = 0\)

IV − II: \(b = -4\)

in II: \(4a - 4 = 0 \Rightarrow a = 1\)

(5) Resultat

\(f(x) = x^2 - 4x + 3\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Aufgabe 4 · Hochpunkt und Wendepunkt 8 P

Der Graph einer ganzrationalen Funktion 3. Grades hat den Hochpunkt \(H(0\,|\,4)\) und den Wendepunkt \(W(1\,|\,2)\). Bestimmen Sie die Funktionsgleichung.

Lösung anzeigen

(1) Ansatz für die Funktionsgleichung

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Hochpunkt \(H(0\,|\,4)\)

2. Wendepunkt \(W(1\,|\,2)\)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(0) = 4\)\(d = 4\) \(f'(0) = 0\)\(c = 0\) 2.\(f(1) = 2\)\(a + b + c + d = 2\) \(f''(1) = 0\)\(6a + 2b = 0\)

(4) Lösen des Gleichungssystems

\(c = 0,\; d = 4\) einsetzen:

I: \(a + b = -2\)

II: \(6a + 2b = 0\)

II − 2·I: \(4a = 4\)

\(a = 1\)

in I: \(b = -3\)

(5) Resultat

\(f(x) = x^3 - 3x^2 + 4\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Probe: \(f''(0) = -6 < 0\) → wirklich ein Hochpunkt ✓ · \(f(1) = 1 - 3 + 4 = 2\) ✓

Aufgabe 5 · Der Sattelpunkt 10 P

Der Graph einer ganzrationalen Funktion 3. Grades geht durch den Ursprung und hat im Punkt \(S(1\,|\,2)\) einen Sattelpunkt (Terrassenpunkt). Bestimmen Sie die Funktionsgleichung.

(Tipp: Ein Sattelpunkt ist ein Wendepunkt mit waagerechter Tangente.)

Lösung anzeigen

(1) Ansatz für die Funktionsgleichung

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Punkt \(O(0\,|\,0)\)

2. Sattelpunkt \(S(1\,|\,2)\)
(Punkt, waagerechte Tangente und Wendestelle bei \(x = 1\))

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(0) = 0\)\(d = 0\) 2.\(f(1) = 2\)\(a + b + c = 2\) \(f'(1) = 0\)\(3a + 2b + c = 0\) \(f''(1) = 0\)\(6a + 2b = 0\)

(4) Lösen des Gleichungssystems

I:\(a + b + c = 2\) II:\(3a + 2b + c = 0\)\(\text{II}-\text{I} \to\) III:\(6a + 2b = 0\)\(\to b = -3a\)

IV: \(2a + b = -2\)

\(b = -3a\) in IV:

\(-a = -2 \Rightarrow a = 2\)

\(b = -6\)

in I: \(2 - 6 + c = 2\)

\(c = 6\)

(5) Resultat

\(f(x) = 2x^3 - 6x^2 + 6x\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

Probe: \(f'(x) = 6x^2 - 12x + 6 = 6(x-1)^2\) → \(f'(1) = 0\) ✓ und \(f'\) wechselt das Vorzeichen nicht → Sattelpunkt ✓
