1. … deren Graph die x-Achse bei 1 schneidet, im Punkt \((-2\,|\,3)\) ein Extremum und bei \(x_0 = 0\) einen Wendepunkt hat.

Ergebnis aufklappen
\(f(x) = \tfrac19 x^3 - 1\tfrac13 x + 1\tfrac29\)
Hattest du das?
Lösungsweg anzeigen

(1) Ansatz für die Funktionsgleichung

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Nullstelle bei \(x = 1\)

2. Extrempunkt \(E(-2\,|\,3)\)

3. Wendestelle \(x = 0\)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(1) = 0\)\(a + b + c + d = 0\)2.\(f(-2) = 3\)\(-8a + 4b - 2c + d = 3\)\(f'(-2) = 0\)\(12a - 4b + c = 0\)3.\(f''(0) = 0\)\(2b = 0 \;\Rightarrow\; b = 0\)

(4) Lösen des Gleichungssystems

Mit \(b = 0\) aus 3.:

I:\(a + c + d = 0\)II:\(-8a - 2c + d = 3\)\(\text{I} - \text{II} \to\)III:\(12a + c = 0\)\(\to c = -12a\)

IV: \(9a + 3c = -3 \;\big|:3\)

\(3a + c = -1\)

III in IV: \(3a - 12a = -1\)

\(a = \tfrac19\)

\(c = -\tfrac{12}{9} = -1\tfrac13\)

in I: \(d = -a - c = 1\tfrac29\)

(5) Resultat

\(f(x) = \tfrac19 x^3 - 1\tfrac13 x + 1\tfrac29\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.
