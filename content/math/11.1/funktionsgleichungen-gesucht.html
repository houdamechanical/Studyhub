Funktions­gleichungen gesucht

Rekonstruktion von Funktionen („Steckbriefaufgaben“): Du kennst Eigenschaften eines Graphen – einen Wendepunkt, ein Maximum, eine Steigung – und sollst daraus die Funktionsgleichung bestimmen. Hier lernst du jeden Schritt so, wie er im Unterricht aufgeschrieben wird.

1Die Idee

Bei der Kurvendiskussion hast du eine Funktion und suchst ihre Eigenschaften (Nullstellen, Extrempunkte, Wendepunkte …). Hier ist es umgekehrt: Die Eigenschaften sind gegeben, die Funktion wird gesucht. Darum heißt das Thema auch Rekonstruktion.

Das braucht man z. B. in der Technik: Eine Skateboard-Bahn, eine Straße oder eine Achterbahn soll ohne Knick an gerade Stücke anschließen – dafür braucht man eine passende Funktionsgleichung.

MerkeJede Eigenschaft liefert eine Gleichung. Mit genauso vielen Gleichungen wie unbekannten Parametern \((a, b, c, \dots)\) entsteht ein lineares Gleichungssystem (LGS), das du löst.

2Der Ansatz: allgemeine Funktionsgleichung

Zuerst schreibst du die allgemeine Gleichung des gesuchten Grades auf – und gleich die Ableitungen dazu, weil fast immer Steigung oder Krümmung vorkommen.

GradAnsatzAbleitungenUnbekannte
2 (Parabel)\(f(x) = ax^2 + bx + c\)\(f'(x) = 2ax + b\)
\(f''(x) = 2a\)		3 → 3 Gleichungen
3\(f(x) = ax^3 + bx^2 + cx + d\)\(f'(x) = 3ax^2 + 2bx + c\)
\(f''(x) = 6ax + 2b\)		4 → 4 Gleichungen
4\(f(x) = ax^4 + bx^3 + cx^2 + dx + e\)\(f'(x) = 4ax^3 + 3bx^2 + 2cx + d\)
\(f''(x) = 12ax^2 + 6bx + 2c\)		5 → 5 Gleichungen
FaustregelGrad \(n\) → \(n+1\) Parameter → du brauchst \(n+1\) Bedingungen. Zähle immer nach, bevor du anfängst zu rechnen!

3Symmetrie spart Arbeit

Achsensymmetrisch zur y-Achse

Nur gerade Potenzen von \(x\) kommen vor. Alle ungeraden Parameter sind 0.

4. Grad: \(b = d = 0\)
\(f(x) = ax^4 + cx^2 + e\)

Punktsymmetrisch zum Ursprung

Nur ungerade Potenzen. Alle geraden Parameter (auch das absolute Glied) sind 0.

3. Grad: \(b = d = 0\)
\(f(x) = ax^3 + cx\)

WichtigJede ganzrationale Funktion 3. Grades ist punktsymmetrisch zu ihrem Wendepunkt. „Punktsymmetrisch zu \(P(-1|0)\)“ heißt also: \(P\) ist der Wendepunkt → \(f(-1) = 0\) und \(f''(-1) = 0\).

Steigung aus einem Winkel\(m = \tan\alpha\). Beispiel: \(45° \to m = \tan 45° = 1\). Fällt der Graph, ist die Steigung negativ: \(m = \tan(180° - \beta)\) ist dann z. B. \(-0{,}63\).

5Das Schema in fünf Schritten

So steht es im Buch – und so solltest du es in der Arbeit aufschreiben:

  1. Ansatz für die FunktionsgleichungAllgemeine Gleichung mit den Parametern \(a, b, c, d\) aufschreiben, dazu die Funktionsterme von \(f'\) und \(f''\).
  2. Eigenschaften der Funktion \(f\)Alle Informationen aus dem Text untereinander auflisten (1., 2., 3. …).
  3. Umsetzen der Eigenschaften in GleichungenJede Eigenschaft mit der Tabelle übersetzen, einsetzen und als Gleichung in \(a, b, c, d\) schreiben.
  4. Lösen des GleichungssystemsGleichungen mit I, II, III, IV benennen und mit dem Additions- oder Einsetzungsverfahren (oder dem WTR) lösen.
  5. ResultatFunktionsgleichung angeben: „\(f(x) = \dots\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.“
Arbeitsblatt-Variante (6 Schritte): 1. Allgemeine Funktionsgleichung angeben · 2. Symmetrieinformationen verarbeiten · 3. Ableitungen aufstellen · 4. Bestimmungsgleichungen und LGS ermitteln · 5. LGS lösen (Additionsverfahren oder WTR) · 6. Funktionsgleichung angeben und ggf. mit GeoGebra prüfen. Das ist dasselbe Vorgehen, nur feiner aufgeteilt.

6Das LGS lösen

Gib jeder Gleichung eine römische Nummer. Neue Gleichungen bekommen neue Nummern (V, VI, VII …), und du schreibst dazu, wie du sie gebildet hast:

NotationBedeutung
\(\text{II} - \text{III}\)Gleichung III von Gleichung II abziehen (Additionsverfahren)
\(2\cdot\text{II}\)Gleichung II mit 2 multiplizieren
\(\text{V} + \text{VI}\)Gleichungen V und VI addieren, damit eine Variable wegfällt
IV in IIIDas Ergebnis aus IV in Gleichung III einsetzen (Einsetzungsverfahren)
ZielBei jedem Schritt verschwindet eine Variable, bis nur noch eine übrig ist. Dann rückwärts einsetzen. Mit dem WTR (Gleichungssystem-Modus) kannst du dein Ergebnis kontrollieren.

7Beispiel: Wendepunkt, Maximum und Wendetangente

Beispiel:Gesucht ist eine ganzrationale Funktion dritten Grades mit dem Wendepunkt \(W(-2\,|\,6)\), die an der Stelle \(x = -4\) ein Maximum hat. Außerdem ist die Steigung der Wendetangente (Tangente im Wendepunkt) bekannt. Sie ist gleich \(-12\).

Lösung:

(1) Ansatz für die Funktionsgleichung
Wir setzen die ganzrationale Funktion dritten Grades unter Verwendung der Parameter \(a, b, c\) und \(d\) allgemein an. Außerdem notieren wir die Funktionsterme von \(f'\) und \(f''\).

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Wendepunkt \(W(-2\,|\,6)\)
(Wendestelle \(x = -2\), Funktionswert \(y = 6\))

2. Maximum bei \(x = -4\)

3. Steigung im Wendepunkt: \(-12\)

(3) Umsetzen der Eigenschaften in Gleichungen

1.\(f(-2) = 6\)\(-8a + 4b - 2c + d = 6\) \(f''(-2) = 0\)\(-12a + 2b = 0\) 2.\(f'(-4) = 0\)\(48a - 8b + c = 0\) 3.\(f'(-2) = -12\)\(12a - 4b + c = -12\)

(4) Lösen des Gleichungssystems

I:\(-8a + 4b - 2c + d = 6\) II:\(-12a + 2b = 0\)\(2\cdot\text{II} \to\) III:\(48a - 8b + c = 0\)\(\text{III}-\text{IV} \to\) IV:\(12a - 4b + c = -12\)
V:\(-24a + 4b = 0\)\(\text{V}+\text{VI} \to\) VI:\(36a - 4b = 12\)

VII: \(12a = 12\)

\(a = 1\)

in II: \(b = 6\)

in III: \(c = 0\)

in IV: \(d = -10\)

Rechnung Schritt für Schritt

\(2\cdot\)II: \(-24a + 4b = 0\) = V.

III − IV: \((48a - 12a) + (-8b + 4b) + (c - c) = 0 - (-12) \Rightarrow 36a - 4b = 12\) = VI.

V + VI: \(12a = 12 \Rightarrow a = 1\).

in II: \(-12\cdot 1 + 2b = 0 \Rightarrow b = 6\).

in III: \(48 - 48 + c = 0 \Rightarrow c = 0\).

in I: \(-8 + 24 - 0 + d = 6 \Rightarrow d = -10\).

Probe: \(f'(-4) = 3\cdot16 - 48 = 0\) ✓ · \(f''(-4) = -24 + 12 = -12 < 0\) → wirklich ein Maximum ✓.

(5) Resultat

\(f(x) = x^3 + 6x^2 - 10\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

8Beispiel: Berührung der Winkelhalbierenden

Beispiel:Der Graph einer ganzrationalen Funktion dritten Grades berührt die Winkelhalbierende des ersten Quadranten bei \(x = 1\) und ändert sein Krümmungsverhalten in \(P(0\,|\,0{,}5)\). Wie lautet die Funktionsgleichung?

Lösung:

(1) Ansatz für die Funktionsgleichung
Wir setzen die ganzrationale Funktion dritten Grades unter Verwendung der Parameter \(a, b, c\) und \(d\) allgemein an. Außerdem notieren wir die Funktionsterme von \(f'\) und \(f''\), da das Krümmungsverhalten mit im Spiel ist.

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

\(f''(x) = 6ax + 2b\)

(2) Eigenschaften der Funktion f

1. Wendepunkt \(W(0\,|\,0{,}5)\)
(Wendestelle \(x = 0\), Funktionswert \(y = 0{,}5\))

2. Punkt \(P(1\,|\,1)\)

3. Steigung bei \(x = 1\): 1

(3) Umsetzen der Eigenschaften in Gleichungen

1. \(f''(0) = 0\)

\(\;\;\;f(0) = 0{,}5\)

2. \(f(1) = 1\)

3. \(f'(1) = 1\)

⇒

\(b = 0\)

\(d = 0{,}5\)

\(a + b + c + d = 1\)

\(3a + 2b + c = 1\)

Warum \(P(1|1)\) und Steigung 1? Die Winkelhalbierende des 1. Quadranten ist \(y = x\). „Berühren bei \(x = 1\)“ heißt: gleicher Punkt \((1\,|\,1)\) und gleiche Steigung 1.

(4) Lösen des Gleichungssystems

\(a + c = 0{,}5\)

\(3a + c = 1\)

⇒

\(c = 0{,}5 - a \Rightarrow 3a + 0{,}5 - a = 1 \Rightarrow 2a = 0{,}5\)

⇒

\(a = 1/4\)

\(c = 1/4\)

(5) Resultat

\(f(x) = \tfrac14 x^3 + \tfrac14 x + 0{,}5\) hat die geforderten Eigenschaften, was man leicht überprüfen kann.

9Beispielrechnung: Funktion 4. Grades

Aufgabe:Eine Funktion 4. Grades ist gesucht. Ihr Graph ist achsensymmetrisch zur y-Achse. Er hat in \(W(1\,|\,0)\) einen Wendepunkt. Die Tangentengerade im Punkt W hat die Gleichung \(y = -2x + 2\).
(Tipp: Die Tangentengerade im Punkt W ist die Gerade, die den Graphen im Punkt W berührt, bzw. so schneidet, dass sie dieselbe Steigung hat wie die gesuchte Funktion im Punkt W.)
  1. Schritt: Allgemeine Funktionsgleichung angebenFunktion 4. Grades: \(f(x) = ax^4 + bx^3 + cx^2 + dx + e\)
    Gesucht sind die Parameter \(a, b, c, d, e\).
  2. Schritt: Symmetrieinformationen verarbeitenAchsensymmetrie zur y-Achse: Nur gerade Potenzen, d. h. \(b = d = 0\)
    \(f(x) = ax^4 + cx^2 + e\)
  3. Schritt: Ableitungen aufstellen\(f'(x) = 4ax^3 + 2cx\)
    \(f''(x) = 12ax^2 + 2c\)
  4. Schritt: Bestimmungsgleichungen und LGS ermitteln
    W ist ein Punkt des Graphen:\(f(1) = 0\)⇒I: \(a + c + e = 0\)
    W ist ein Wendepunkt:\(f''(1) = 0\)⇒II: \(12a + 2c = 0\)
    Die Steigung in W ist \(-2\):
    (die Steigung der Tangente)    		\(f'(1) = -2\)⇒III: \(4a + 2c = -2\)
  5. LGS lösen, entweder per Additionsverfahren, oder mit dem WTR
    II − III:IV: \(8a = 2\)⇒ \(a = \tfrac14\)
    IV in III:V: \(1 + 2c = -2\)⇒ \(c = -\tfrac32\)
    IV, V in I:VI: \(\tfrac14 - \tfrac32 + e = 0\)⇒ \(e = \tfrac54\)
  6. Funktionsgleichung angeben und ggfs. mit GeoGebra prüfen
    \(f(x) = \tfrac14 x^4 - \tfrac32 x^2 + \tfrac54\)

10Anwendungen: Skateboard-Bahn und Basketball

Beispiel:Aus Beton soll eine Skateboard-Bahn für den Park so gebaut werden, wie es die Abbildung zeigt. Die gebogenen Teile sollen ohne Knick an die geraden Teile anschließen. Ermitteln Sie für die Konstruktion die Gleichung einer Polynomfunktion, deren Graph dem gebogenen Teil nahe kommt. Entnehmen Sie die Maße der Skizze. (Skizze: Höhenunterschied 3 m, Länge 4 m, Ursprung in der Mitte der Bahn.)

Lösung:

Der Skizze können wir entnehmen, dass die gesuchte Polynomfunktion dritten Grades ist, die die folgenden Bedingungen erfüllen muss: Ihr Graph ist punktsymmetrisch zum Ursprung des eingezeichneten Koordinatensystems und geht durch den Punkt \(P(0\,|\,0)\). Ein Tiefpunkt der Polynomfunktion liegt bei \(T(2\,|\,-1{,}5)\). Somit ergibt sich folgende Rechnung:

Ansatz für f:

\(f(x) = ax^3 + bx^2 + cx + d\)

\(f'(x) = 3ax^2 + 2bx + c\)

Eigenschaften von f:

(1) symmetrisch zu O

(2) \(f(0) = 0\)

(3) \(f'(2) = 0\)

(4) \(f(2) = -1{,}5\)

→

Gleichungssystem:

\(b = 0\)

\(d = 0\)

\(12a + 4b + c = 0\)

\(8a + 4b + 2c + d = -1{,}5\)

→

Lösung:

\(b = 0\)

\(d = 0\)

\(a = 3/32\)

\(c = -9/8\)

Wie kommt man auf a und c?

Mit \(b = d = 0\) bleiben: I: \(12a + c = 0 \Rightarrow c = -12a\) und II: \(8a + 2c = -1{,}5\).

I in II: \(8a - 24a = -1{,}5 \Rightarrow -16a = -1{,}5 \Rightarrow a = \tfrac{3}{32}\); dann \(c = -12\cdot\tfrac{3}{32} = -\tfrac{9}{8}\).

Probe: \(f'(2) = 3\cdot\tfrac{3}{32}\cdot 4 - \tfrac98 = \tfrac98 - \tfrac98 = 0\) ✓ · \(f(2) = \tfrac{3}{32}\cdot 8 - \tfrac98\cdot 2 = \tfrac34 - \tfrac94 = -1{,}5\) ✓

Resultat: Das Profil der Skateboard-Bahn wird durch die Funktion \(f(x) = \tfrac{3}{32}x^3 - \tfrac98 x\) beschrieben.
Beispiel: Freiwurf beim Basketball
Holger Geschwindner, der Trainer von Dirk Nowitzki, erkannte, dass man beim Freiwurf den Korb (D = 45 cm) mit dem Ball (d = 24 cm) nicht zu flach treffen darf. Der Einschlagwinkel \(\beta\) muss mindestens 32° betragen, sonst prallt der Ball am vorderen oder hinteren Korbrand ab. (Skizze: Abwurf in 2,70 m Höhe, Korb in 3,05 m Höhe, waagerechter Abstand 4,23 m; Koordinatenursprung im Abwurfpunkt.)
  1. Weisen Sie nach, dass Geschwindners Resultat richtig ist. Verwenden Sie dazu das rechtwinklige Dreieck in der oben dargestellten Skizze mit dem Einflugkanal.
  2. Die Flugbahn des Balles beim Freiwurf kann durch eine quadratische Parabel der Form \(f(x) = ax^2 + bx + c\) modelliert werden. Verwenden Sie das Koordinatensystem und die Daten aus der Zeichnung sowie das Ergebnis von a), um a, b und c zu bestimmen.
  3. Der Spieler darf den Ball nicht zu flach abwerfen, damit er nicht abprallt. Wie groß ist der minimale Abwurfwinkel \(\alpha\) für den oben dargestellten Spieler?

Lösung zu a:
Der Einflugkanal des Balles in den Korb muss mindestens so breit sein wie der Ball, also 24 cm. Mit diesen Daten lässt sich \(\beta\) im obigen rechtwinkeligen Dreieck bestimmen. Resultat: \(\beta = 32{,}23°\).

Minimal Einschlagwinkel

\(\sin\beta = \dfrac{\text{Gk}}{\text{Hyp}} = \dfrac{24}{45} = 0{,}5333\)

\(\beta = 32{,}23°\)

Lösung zu b:
Wir besitzen drei Informationen:

I. Abwurf im Punkt \(P(0\,|\,0)\)

II. Korb bei \(K(4{,}23\,|\,0{,}35)\)

III. Mindestwinkel \(\beta = 32{,}23°\) bei \(x = 4{,}23\)

Diese liefern ein Gleichungssystem mit den Lösungen \(a = -0{,}1685\), \(b = 0{,}796\) und \(c = 0\).

Resultat:

\(f(x) = -0{,}1685x^2 + 0{,}796x\)

Parabelgleichung

Ansatz: \(f(x) = ax^2 + bx + c,\; f'(x) = 2ax + b\)

I: \(f(0) = 0\)

II: \(f(4{,}23) = 0{,}35\)

III: \(f'(4{,}23) = \tan(147{,}77°) = -0{,}63\)

I: \(c = 0\)

II: \(17{,}89a + 4{,}23b = 0{,}35\)

III: \(8{,}46a + b = -0{,}63\)

\(\Rightarrow c = 0,\; b = 0{,}796,\; a = -0{,}1685\)

Lösung zu c:
Den Mindestabwurfwinkel \(\alpha\) erhalten wir aus der Abwurfsteigung: \(\tan\alpha = f'(0)\).

Resultat: Der Abwurfwinkel für einen möglichen Korbwurf beträgt mindestens 38°.

Minimaler Abwurfwinkel

\(\tan\alpha = f'(0)\)

\(\tan\alpha = 0{,}79\)

\(\alpha = 38{,}52°\)

Warum 0,35 und 147,77°? Der Korb hängt \(3{,}05 - 2{,}70 = 0{,}35\) m über dem Abwurfpunkt. Der Ball fällt am Korb, die Steigung ist also negativ: Der Winkel zur x-Achse ist \(180° - 32{,}23° = 147{,}77°\), und \(\tan 147{,}77° \approx -0{,}63\).

11Typische Fehler

1. Bei einem Punkt nur eine GleichungEin Extrempunkt \(T(2|-4)\) liefert zwei Gleichungen: \(f(2) = -4\) und \(f'(2) = 0\). Ein Wendepunkt ebenso: \(f(x_W) = y_W\) und \(f''(x_W) = 0\).
2. Falsche Ableitung benutztSteigung / Extremum → \(f'\). Wendepunkt / Krümmung → \(f''\). Punkt → \(f\).
3. Vorzeichen beim Einsetzen\(f(-2)\): \(a\cdot(-2)^3 = -8a\), aber \(b\cdot(-2)^2 = +4b\). Klammern setzen!
4. Symmetrie vergessenWer die Symmetrie nicht nutzt, hat zu wenige Gleichungen für zu viele Unbekannte.
5. Keine ProbeSetze am Ende in alle Bedingungen ein – ein Rechenfehler fällt sofort auf.

12Kurz-Check

1. „Der Graph hat bei \(x = 3\) einen Wendepunkt.“ Welche Gleichung gehört dazu?

Wendestelle → die zweite Ableitung ist null.

2. Eine Funktion 3. Grades ist punktsymmetrisch zum Ursprung. Welcher Ansatz passt?

Punktsymmetrie zum Ursprung → nur ungerade Potenzen: \(b = d = 0\).

3. Der Graph schneidet die x-Achse bei \(x = 2\) unter 45°. Welche Steigung hat er dort?

\(m = \tan 45° = 1\), also \(f'(2) = 1\) (und zusätzlich \(f(2) = 0\)).
